GraphPaper bundles a resized JPEG of this scan as `ui/graph-paper.jpg`. The sidebar crops it through CSS and applies a translucent light overlay for legibility. No endorsement is implied. The image retains its own CC BY 2.0 license, separate from the MIT application code.

The graph canvas, interface icons and atlas mark are vector interface elements, not an AI-generated screenshot. No generated mockup is shipped as the interface.
