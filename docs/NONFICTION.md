# Nonfiction workflow

Use Nonfiction for essays, reports, cultural analysis and source-led articles. Choose [Science](SCIENCE.md) instead when you need scholarly database searching, a recorded screening process and academic manuscript exports.

## Start with a question, not a compulsory conclusion

In the Creative brief, specify the audience, format, voice, target length and the issue you want to investigate. A productive direction leaves room for the sources to surprise you:

> Explore when public lighting serves safety and when it intrudes on private rest. Address the strongest argument for brighter streets.

This is a suggested brief, not a factual claim about lighting research. The included nonfiction demo uses invented illustrative notes; replace them with real evidence before publication.

## Prepare the source library

Upload the complete material you have permission to use. Keep reporting, opinion, background inspiration and style examples distinct. **Voice** samples guide expression but are not factual evidence. Read the imported text and check PDF warnings before relying on it.

Original documents are not automatically proof of their contents. Where sources disagree, keep the disagreement visible rather than deleting the inconvenient source.

## Build and inspect the graph

Extraction processes the planned source chunks, preserving quotation anchors and relationship status. Cached unchanged chunks reduce repeated extraction work. A node may describe an attributed claim rather than something the application endorses.

Inspect a few important nodes and relationships. An **exact source match** locates words in your imported text; an **inferred** edge is a possible interpretation. Paths can reveal an overlooked connection, but a chain of edges does not prove causation. [Graph controls →](GRAPH-AND-JEV.md)

If you change source content or roles after building the graph, rebuild it before relying on coverage. Pinning a concept influences discovery; it does not turn a weak connection into evidence.

## Choose an angle

The angle stage explores distinct structures such as contradiction, convergence, divergence and cross-community links. With JEV connected, candidates receive separate editorial judgments; without it, results remain explicitly unscored.

Read the thesis, counterargument, evidence links and unresolved questions. Use **Take this angle**, edit the suggestion, or add **Your own angle**. Selecting a candidate does not resolve missing evidence. Import additional sources when necessary.

## Make the outline do real work

Each section should change what the reader understands. Edit its purpose, beats and planned word count, and reorder sections before drafting. Source IDs make it possible to return to the material behind a section.

The writer produces sections sequentially and then reviews the whole draft. The context contains selected relevant passages and prior prose, not necessarily the whole corpus on every call. Avoid interpreting a complete-looking article as evidence that every source was read in full at every stage.

## Edit, verify, export

The writing desk has text, split and preview views. Internal `[S1]` references are clickable source links. Review checks include citation-ID integrity and a sampled examination of load-bearing claims; a valid ID alone does not prove support.

Use an explicit revision instruction to change emphasis or structure. Use Humanize/Deslop for prose work and inspect the proposal before acceptance. Earlier drafts and generated checkpoints remain in Versions.

For ordinary nonfiction, exports retain source identifiers and a source list. Academic author-year formatting belongs to [Science and APA export](EXPORTS-AND-APA.md). Read the actual source passages, check quotations and figures, and resolve important evidence gaps before publishing.
